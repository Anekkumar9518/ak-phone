A phone that actually works, in a web page.

AK Phone is an Android-style phone simulator with 28 working apps and 9 games: a live browser, a voice assistant, a recorder, translation, live currency rates, a QR scanner and a speed test. No framework and no build step. Open index.html and it runs.

  • Unlock swipe up or tap
  • Quick settings swipe down from the top
  • All apps swipe up on the home screen
  • Power menu hold the power key
  • Screenshot quick settings → Screenshot
  • Back the ◀ button or Esc

What's inside

System

Boot animation, lock screen, status bar with your real battery level (where the browser shares it), notification shade with quick-settings tiles and brightness, home screen with folders, app drawer with search, recents, back/home/recents navigation, power menu, charging and low-battery alerts, vibration, light and dark themes, and an on-screen keyboard.

Apps

Browser (live sites and Google), Store, Settings, Phone, Messages, Camera, Gallery, Maps, Weather (live), Clock with stopwatch and timer, Calculator, Calendar, Notes, Files, voice Assistant, Music (live radio), Videos, Device Info, QR scanner and generator, and an internet Speed Test.

Tools new

Recorder with a live waveform, Translate in 16 languages with read-aloud, Dictionary with pronunciation, Currency with live ECB rates, News (Hacker News top stories), Paint with undo, a two-octave Piano, a Compass with spirit level, and a Screenshot tile that saves the screen to Gallery.

Games

2048, Tic Tac Toe (an unbeatable minimax bot), Snake, Flappy, Memory, Minesweeper, Bricks, Sudoku and Lead Catcher. Install them from the Store; best scores are saved on your device.

How it works

Each app is a function that gets an empty <section> and returns hooks like show, hide and back. A small window manager opens, switches and closes them, and keeps the state (installed games, notes, settings) in localStorage.

Real browser APIs do the heavy lifting: Web Speech for the assistant, MediaRecorder and Web Audio for the recorder and piano, getUserMedia and BarcodeDetector for the camera and QR scanner, DeviceOrientation for the compass, the Battery API for the status bar, and the Vibration API for haptics.

Live data comes from free, keyless APIs: Open-Meteo (weather), Frankfurter (exchange rates), MyMemory (translation), dictionaryapi.dev, Hacker News, and Cloudflare's speed test endpoints. Nothing you record, draw or type is uploaded.

It's a simulator: real Android apps and Google Play can't run inside a web page, so every app is written for this phone. Many sites refuse to be shown inside other pages, so the browser opens those as snapshots with a button to the live site.
